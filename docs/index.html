🎬 AMVFX

Open-source VFX passes generator. Turn any image or video into relightable passes — the Beeble-style workflow, rebuilt entirely from open models.

View on GitHub AMVFX vs Beeble

The passes

One source in, a full pass stack out — as PNG sequences, per-pass MP4s, and a single 16-bit multi-layer EXR per frame with the same layer names compositors expect (Source / Alpha / Normal / Basecolor / Depth / …). Built for relighting in Blender, Unreal and Nuke.

Alpha

Clean cut-out matte of the subject (BiRefNet, MIT).

Depth

Normalized depth for fog, DOF and relight falloff (Depth Anything V2 Small, Apache-2.0).

Normal

Object-frame normals, OpenGL convention (Beeble-matching) or DirectX. Model normals via Marigold, MoGe-2, or NormalCrafter for video.

Base Color

De-lit albedo with the lighting baked out (Marigold IID).

Roughness

Per-pixel gloss variation for believable reflections (Marigold IID).

Metallic

Metal vs dielectric separation (Marigold IID).

Specular

True PBR F0, derived the standard way: mix(0.04, base color, metallic).

AO (bonus)

Ambient occlusion derived from depth, for contact grounding.

Two profiles

ProfileHardwareWhat runs
liteCPU, ONNXDepth Anything V2 Small + BiRefNet; normals & AO derived from depth. ~18 s per image.
gpuGPU (runs on CPU too, slower)Adds Marigold IID for base color / roughness / metallic and Marigold Normals; optional NormalCrafter for temporally consistent video normals.

Every model is openly licensed — Apache-2.0, MIT, or CreativeML Open RAIL++-M — and every job writes a manifest.json recording exactly which model or derivation produced each pass. Full license audit: MODELS.md.

Quickstart

git clone https://github.com/aaigenerational-glitch/AMVFX.git
cd AMVFX
pip install -r requirements-lite.txt

# image or video in -> passes out (PNG + MP4 + multi-layer EXR)
python -m amvfx input.mp4 --out out/ --profile lite

# or launch the web app
python app.py
Honest scope: AMVFX is a clean-room re-creation of the VFX-pass workflow using only published open models — no Beeble code, weights or assets (their SwitchLight models are proprietary). Where AMVFX still trails Beeble, the comparison doc says so plainly. This page is the project site; the interactive app runs locally (python app.py) or on Hugging Face Spaces.
